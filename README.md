# PROJECT MAV-A1 · Martian Subterranean Vanguard

**Live site: [mav-a1.pages.dev](https://mav-a1.pages.dev)**

Backup copy: [ayhamalqady9-glitch.github.io/MAV-A1](https://ayhamalqady9-glitch.github.io/MAV-A1/)

A scroll-driven 3D mission story: MAV-A1, a proposed autonomous six-rotor hexacopter, explores a skylight on
Arsia Mons and maps the lava tube beneath it with LiDAR-SLAM, relaying its data home through breadcrumb nodes.

- Built with HTML, CSS and JavaScript, and three.js (WebGL) for the real-time 3D scenes.
- Uses NASA imagery and data: MOLA topography, THEMIS cave-skylight images, HiRISE images of the Arsia Mons pit.
- Works offline: fonts and the three.js library are included in the repository.

Concept mission visualization. Values marked SIM on the site are simulated. MAV-A1 is a student concept design.
NASA imagery is used with credit; no NASA endorsement is implied.
